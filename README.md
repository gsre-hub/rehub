# RE Hub · app del iPhone

App instalable (PWA) para consultar los pisos y apuntar incidencias desde el móvil.

- Los datos **no** están aquí: se leen del Libro maestro a través del puente «RE Hub API» (Google Apps Script), protegido con clave.
- Se abre con PIN o Face ID y funciona en parte sin conexión.
- Publicada con GitHub Pages: https://gsre-hub.github.io/rehub/
